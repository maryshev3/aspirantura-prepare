# Методы нормализации критериев

**Нормализация критериев** — это ключевая процедура в многокритериальном анализе, направленная на приведение разнородных критериев (с различными единицами измерения, масштабами и направлениями оптимизации) к сопоставимому, безразмерному виду. Это необходимо для корректного сравнения альтернатив и применения методов свертки или выбора.

Производится нормализация с помощью определённого преобразования, которое должно удовлетворять следующим критериям:

- иметь общее начало отсчета и один порядок изменения значений на всем множестве допустимых решений
- быть монотонным преобразованием, т.к. должно сохранять отношение предпочтения на множестве D (множество решений), т.е. не менять множество Парето
- учитывать необходимость минимизации отклонения от оптимальных значений по каждой целевой функции

Множество Парето (парето-оптимальные альтернативы) — это набор компромиссных решений в задачах с несколькими критериями, где улучшение одного показателя невозможно без ухудшения другого. В него входят все не доминируемые варианты, из которых принимающий решения делает окончательный выбор.

## Метод Минимакс

Минимакс — линейное преобразование данных в диапазоне $[0..1]$, где минимальное и максимальное масштабируемые значения соответствуют $0$ и $1$ соответственно;

Для максимизируемых критериев (чем больше, тем лучше):

$k_i^{norm} = \frac{k_i - min(k_i)}{max(k_i) - min(k_i)}$

Для минимизируемых критериев (чем меньше, тем лучше):

$k_i^{norm} = \frac{max(k_i) - k_i}{max(k_i) - min(k_i)}$

Метод является простым и наглядным, однако чувствителен к выбросам в данных, так как опирается на min и max значения.

## Метод идеальной точки (относительно наилучших значений)

В основу метода "идеальной точки" положен расчёт расстояния в
многомерном пространстве критериев между точкой, соответствующей
идеальной альтернативе, и точкой, соответствующей рассматриваемой
альтернативе. Идеальной называется такая альтернатива, которая имеет
наилучшие значения всех критериев. Естественно, в реальности такой
альтернативы не существует. Но наиболее приемлемой считается
альтернатива, у которой расстояние от "идеальной точки" минимально:

$R_{Ai} = min_{i} \sqrt[N]\sum_{i = 1}^{N} (x_{id j} - x_{ij})^2$,

где $N$ - количество критериев оценки альтернатив;

$x_{id j}$ - идеальное значение по j-му критерию для идеального варианта;

$x_{ij}$ - значение по $j$ критерию для $i$ альтернативы.

Для нормализации критерия используется формула:

$k_i^{norm} = \frac{k_i}{k_{i}^{ideal}}$

Данный метод учитывает не диапазон, а целевое значение, однако требует обоснованного выбора идеальной точки, которая может быть недостижима.

## Модернизация метода Минимакса

Метод Минимакса можно модернизировать, используя априорную информацию вместо статистической.

Диапазон нормализации задаётся не статистикой выборки (min/max), а априорными допустимыми границами изменения критерия, которые известны из физического, экономического или технического смысла задачи. Например, температура может быть ограничена 0°C и 100°C, а не фактическими min/max в данных.

Нормализованное значение вычисляется по формуле:

$k_{i}^{norm} = \frac{k_i - a_i}{b_i - a_i}$,

где $a_i$ и $b_i$ - нижняя и верхняя допустимые границы критерия $k_i$.

Его цель - обеспечить равномерное и сопоставимое «пространство» для всех критериев в рамках их физически или логически осмысленных пределов, а не в зависимости от случайных экстремумов в данных.

Стоит учитывать, что критерии, основанные только на значениях критериев являются $\epsilon$ неустойчивыми.

## Метод Z-оценки

Метод Z-оценки (Z-score normalization или стандартизация) — это статистический метод преобразования данных, при котором значения критериев приводятся к единому масштабу со средним арифметическим, равным $0$, и стандартным отклонением, равным $1$.

Для каждого исходного значения критерия $x$ Z-оценка вычисляется по формуле:

$z = \frac{x - \mu}{\sigma}$

где $x$ - исходное значение критерия;

$\mu$ - среднее арифметическое значение всех данных для этого критерия;

$\sigma$ - стандартное отклонение (среднеквадратическое отклонение) выборки.

При этом, $\sigma = \sqrt{\frac{\sum{(x_i - \mu)^2}}{N}}$

Решение многокритериальной задачи, найденное этим методом нормализации, может существенно измениться при изменении пассивных ограничений — таких, которые не влияют на область Парето-оптимальных решений. Это означает, что два эксперта, по-разному формализуя одну и ту же задачу (добавляя или изменяя несущественные ограничения), могут получить совершенно разные результаты, используя один и тот же метод нормализации.
